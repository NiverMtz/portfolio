## 📌 Stack

Proyecto creado con:
* ANGULAR
* TS
* SCSS
* PRIMENG

Desplegado en **Vercel**. El formulario de contacto usa una función serverless
(`api/contact.ts`) que reenvía a [Web3Forms](https://web3forms.com); la
`WEB3FORMS_KEY` se configura como *Environment Variable* en Vercel.
